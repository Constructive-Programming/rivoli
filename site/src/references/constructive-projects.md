# Constructive projects

rivoli shares the constructive.dev brand and the same Cloudflare Pages deployment with
these projects. Their sites are built with Laika; rivoli's is built with mdBook, the Rust
ecosystem's default.

<div class="rv-links">

## eo

An existential optics library for Scala 3, built on cats. A single `Optic` trait,
parameterised over a carrier, unifies every optic family, and composition across families
goes through bridges rather than hand-written overloads.

- [Documentation](https://eo.constructive.dev/)
- [Source](https://github.com/Constructive-Programming/eo)

## cardinality

Counts how many values a type has and how many pure, total implementations a signature
allows, so a design review can see how much a type rules out.

- [Documentation](https://cardinality.constructive.dev/)
- [Source](https://github.com/Constructive-Programming/scala-cardinality)

## fixed

A purely functional language that works at the capability (typeclass) level, in the
style of tagless final encoding, with algebraic effect handlers and quantitative types
for in-place update.

- [Documentation](https://fixed.constructive.dev/)
- [Source](https://github.com/Constructive-Programming/fixed)
